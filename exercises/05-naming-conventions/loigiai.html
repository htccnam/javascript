Bài tập 05: Quy Ước Đặt Tên (Naming Conventions)

Luyện tập chuẩn hóa Clean Code: Boolean dạng câu hỏi, số ít/số nhiều, Động từ + Tân ngữ, Hằng số bất biến và Class Private Field.

Bấm F12 (hoặc chuột phải chọn Kiểm tra / Inspect) → chuyển sang tab Console để xem kết quả thực thi.

Nội dung kiểm chứng:

  • Phần 1: Chuẩn hóa biến Boolean dạng câu hỏi Yes/No (is, has, can), loại bỏ phủ định kép, danh từ số ít vs số nhiều.
  • Phần 2: Chuẩn hóa hàm theo mẫu Động từ + Tân ngữ, phân loại hằng số toàn cục UPPER_SNAKE_CASE vs camelCase, Class & Private fields (#).
  • Phần 3: Refactor đoạn mã legacy thương mại điện tử sang chuẩn Clean Code 100% tiếng Anh và Module BankAccount.
