🩺 Bí kíp chẩn đoán của Dr. JavaScript (4 Ca Bệnh Khó):

Ca bệnh Triệu chứng nhầm lẫn Công thức chẩn đoán chuẩn 100%
1. Number typeof NaN === "number" typeof val === "number" && !isNaN(val)
2. Null typeof null === "object" ⚠️ val === null
3. Array typeof [] === "object" Array.isArray(val)
4. Object Trùng cả null & mảng [] typeof val === "object" && val !== null && !Array.isArray(val)
