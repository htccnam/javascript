🔑 Key Takeaways

  • && trả về giá trị falsy đầu tiên HOẶC giá trị cuối cùng nếu tất cả truthy
  • || trả về giá trị truthy đầu tiên HOẶC giá trị cuối cùng nếu tất cả falsy
  • !!value hoặc Boolean(value) → ép kiểu thành boolean primitive
  • KHÔNG BAO GIỜ dùng new Boolean() - nó tạo object wrapper!
  • Luôn dùng === thay vì == (trừ khi check == null)
  • ?? (nullish coalescing) chỉ fallback khi null/undefined, giữ 0, "", false
